# RemoteOps 管理控制台：中英文与响应式布局

## 功能范围

RemoteOps Web 管理后台通过轻量原生 JavaScript 国际化模块 gateway/ui/i18n.js 实现简体中文（zh-CN）与英文（en-US）即时切换，不需要重载页面，不需要第三方翻译服务或 CDN。

支持的界面包括登录和未初始化引导、Owner Token 验证、TOTP 二维码绑定、八个主要管理页面，以及工具操作通知、表单标签、空状态、动态数量和日期文案。

语言控制按钮位于顶栏。当前界面为中文时显示 EN，当前界面为英文时显示 中文。语言选择保存在当前浏览器 localStorage 的 remoteops.ui.language 键；不同浏览器互不影响，不写入 Gateway SQLite，也不绑定管理员令牌。没有保存选择时按照浏览器首选语言判断；非英文环境默认简体中文。可通过 ?lang=en-US 或 ?lang=zh-CN 指定首次语言，登录和 TOTP 初始化页面共用同一偏好。

## 技术结构

- gateway/ui/i18n.js：集中词典、语言选择与存储、动态文本翻译、DOM MutationObserver 监听。
- gateway/ui/index.html：语言切换入口及同源脚本引用。
- gateway/ui/app.js：保留操作逻辑和路由；小屏确保导航选中项可见。
- gateway/ui/console-views.js：使用当前语言的 Intl.NumberFormat 格式化统计数字。
- gateway/ui/style.css：修复设置面板间距、窄屏按钮换行、操作区错位和不一致的平台标记。
- gateway/web.js：服务器渲染的 TOTP 初始化页面引用相同语言模块。

设备名称、主机名、文件内容、代码、Token、工具输入等业务数据保持原文。代码节点和明确标记 data-i18n-ignore 的节点禁止自动翻译。

## 安全与部署

- 不修改 API、Cookie、CSRF、OAuth、TOTP、设备配对或执行权限。
- 仅添加同源 /admin/i18n.js 资源，保留现有严格 CSP 的 script-src self 限制。
- 不使用 eval、innerHTML、远程 JavaScript 或在线机器翻译。
- 语言偏好仅影响当前浏览器界面，不覆盖管理员配置的名称或插件描述。
- 不在公开仓库保存个人设备、真实 IP 或密钥。

## 验收

1. 在 1440、768、390、320px 视口检查中英文八个管理视图。
2. 登录与 /admin/setup 均有明显的语言切换操作。
3. 切换后立即生效，刷新后与初始化页面均保留语言偏好。
4. 系统设置面板间距一致，小屏退出按钮不换行，导航选中项可见。
5. 动态设备计数、图表、下拉选项、操作提示不能明显中英混杂。
6. 浏览器无脚本错误或页面横向溢出，不放宽 CSP。
7. 执行 npm ci、npm test 和 python3 scripts/secret_scan.py，CI 在 Linux/macOS/Windows 通过。
8. VPS 更新采用独立目录、SQLite 在线备份及 systemd 切换回滚；不修改 Agent、Tailscale 或 OAuth。
