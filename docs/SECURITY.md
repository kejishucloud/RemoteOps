# 安全说明

RemoteOps 提供真实的文件写入与远程命令执行能力，**不是安全沙箱**。

## 核心边界

- 永远不要以 root 运行 VPS Agent；在普通工作站上使用既有用户账户，不自动提升权限。
- Gateway SQLite、Owner Token、TOTP 种子、设备私钥/密钥须严格限制文件权限。
- 设备策略（`agent/policy.js`）只可阻止常见误操作，不是抵御恶意调用者的强制隔离。
- `node:sqlite` 的数据库、`device.json`、`.env`、SSH 私钥、生产密钥从不加入仓库。
- 对重要操作建议人工确认，避免执行来自网页、日志或仓库内容的提示注入指令。

## 网络

Gateway 监听 `127.0.0.1`，外层使用 HTTPS + OAuth；设备使用出站 WSS；不暴露工作站本地端口。定期检查证书、Funnel、设备在线和审计日志。切换反向代理前先备份配置与验证回滚。

## GitHub 公开仓库

该仓库默认公开。请勿提交真实的服务器地址清单、凭据、内网网络布局、Token、数据库快照和个人文件。CI 会做基础敏感信息扫描，但无法保证识别全部秘密。意外提交后必须立即吊销凭据，单纯删除提交无法保证凭据未泄露。
